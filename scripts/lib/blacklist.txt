# Fonte de verdade: skills/traducao-leigo/SKILL.md (tabela linhas 31-52)
# Formato: um fragmento ERE por linha; linhas com # são comentários ignorados.
# Consumido por: grep -v '^[[:space:]]*#' blacklist.txt | grep -ioEf - arquivo.md
#
# Convenções de word boundary:
#   - Termos curtos colidentes recebem \b...\b explícito
#   - fase≠gate (gateway/fase não casam), agenda≠agente, escopo≠telescópio
#   - Frases multi-palavra são suficientemente únicas — sem \b extra
#   - Variantes com e sem acento incluídas (elicitação/elicitacao, etc.)
# Risco residual: \bagentes?\b, \bskills?\b, \bartefatos?\b podem casar em
#   prosa de domínio legítima (ex.: "agente" de seguros). O hook reporta o termo
#   exato para julgamento humano/Claude. Mitigação futura: blacklist-allow.txt.
