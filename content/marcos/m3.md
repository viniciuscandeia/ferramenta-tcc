## Loop M3

> **TodoWrite:** ao iniciar M3 e após cada bloco concluído, atualizar `TodoWrite` conforme MAPA DE PROGRESSO em `content/orchestrator.md` (Etapa 3). Marcar `completed` ao encerrar cada bloco; loop-back CRITICAL: reverter apenas o item 3.4 ("Conferir se está tudo consistente") e os itens reabertos do documenter para `in_progress`. Nunca expor nome de skill, marco ou gate.

O orquestrador executa blocos alternados na mesma sessão.

### Bloco DOCUMENTER — Iteração N

Adotar persona documenter. Executar em ordem:
1. Use skill `requisito-ears` agora.
2. Use skill `modelagem-visual` agora → produz `documentos-tecnicos/03-documento/03.3-diagramas.md` + subconjunto leigo-safe (seção `<!-- LEIGO-SAFE-START/END -->`) para `traducao-gate`.
3. Use skill `srs-ireb-montagem` agora → produz `documentos-tecnicos/03-documento/03-srs-completo.md` (8 seções IREB §3.3.3, diagramas embutidos).

### Bloco CHECKER — Iteração N

Adotar persona checker. Executar em ordem:
1. Use skill `analyze-cross-artifact` agora → acrescenta seção "## Análise — Iteração N — \<data\>" em `documentos-tecnicos/03-documento/03.1-analyze-report.md`.
2. Use skill `validacao-checklist-ireb` agora.
3. Use skill `rastreabilidade-matriz` agora → produz `documentos-tecnicos/03-documento/03.2-rastreabilidade.md`.
4. Verificar `documentos-tecnicos/03-documento/03.1-analyze-report.md`: se contém CRITICAL → incrementar `loop_m3_iteracoes`, voltar ao Bloco DOCUMENTER. Se não → prosseguir para Fechamento.

### Fechamento

Adotar persona documenter:
1. Use skill `traducao-leigo` agora.
2. Use skill `traducao-gate` agora → produz `documentos-para-leigo/03-documento/03-documento-do-projeto.md`.
3. Executar C4.4 + C4.5; só então abrir Gate 3.

Parada: loop encerra quando `analyze-report.md` não tem issues CRITICAL (convergência) ou quando usuário decide parar. A partir da 3ª rodada, perguntar ao usuário se quer continuar (ver `content/constitution.md`).
