## ISO/IEC 25010:2023 — Software Product Quality Model

| Campo | Valor |
|---|---|
| Número | ISO/IEC 25010:2023 |
| Título completo | Systems and software engineering — SQuaRE — Product quality model |
| Publicado por | ISO / IEC |
| Ano | 2023 (cancela e substitui 25010:2011) |
| Uso na ferramenta | Categorias de qualidade para RNFs: desempenho, segurança, usabilidade, confiabilidade, manutenibilidade, portabilidade, compatibilidade, safety |
| Acesso oficial | [iso.org/standard/78176.html](https://www.iso.org/standard/78176.html) |
| Preview online (ISO OBP) | [iso.org/obp/ui/#iso:std:iso-iec:25010:en](https://www.iso.org/obp/ui/#iso:std:iso-iec:25010:en) |
| Resumo gratuito | [quality.arc42.org/standards/iso-25010](https://quality.arc42.org/standards/iso-25010) (CC BY-SA 4.0) |

**Características da versão 2023:**
- 9 características de qualidade (vs 8 em 2011)
- Adições: Safety, Interaction Capability (ex-Usability), Flexibility (ex-Portability)
- Novos subcaracterísticos: inclusivity, self-descriptiveness, resistance, scalability

Para o documento completo: ABNT, Portal CAPES, ou compra (~CHF 155).
