# Caminhos do Usuário (Fluxos)

Este documento descreve o passo a passo de como a pessoa usa o aplicativo para realizar suas tarefas.

## 1. Montando um Novo Treino
1. O usuário abre o aplicativo.
2. Escolhe a opção de criar um novo treino.
3. Dá um nome ao treino (ex: Peito e Tríceps).
4. Adiciona um exercício à lista.
5. Define os detalhes: quantidade de séries e classifica cada uma (Aquecimento, Reconhecimento ou Trabalho).
6. O aplicativo sugere os pesos das séries iniciais com base na carga da série de trabalho. O usuário pode ajustar se desejar.
7. Salva o exercício e repete o processo para os demais.

## 2. Realizando o Treino no Dia a Dia
1. O usuário escolhe o treino que vai fazer hoje.
2. O aplicativo mostra a lista de exercícios.
3. O usuário inicia o primeiro exercício.
4. Ao terminar a primeira série, ele aperta o botão de "concluído". 
   - Se o número de repetições foi diferente do planejado, ele ajusta o valor antes de confirmar.
5. O aplicativo inicia o cronômetro de descanso imediatamente.
6. Quando o tempo acaba, o aplicativo vibra/toca um alarme.
7. O usuário faz a próxima série e repete até terminar o exercício e, depois, o treino.

## 3. Acompanhando o Progresso
1. O usuário acessa a área de gráficos.
2. Seleciona o que deseja ver (ex: evolução no supino ou volume total da semana).
3. O aplicativo mostra o gráfico com as informações salvas.
